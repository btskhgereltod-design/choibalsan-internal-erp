# Repository Agent Entry Point

This repository contains both the legacy Choibalsan application and the newer
OVERVA platform. Do not assume they are one product or one data boundary.

## OVERVA Work

For any task concerning OVERVA, `overva.com`, or files under `erp-v2/`, read and
follow `erp-v2/AGENTS.md` before proposing or implementing material work. That
file routes agents to the current state, architecture, decisions, and product
vision.

## Legacy Application Work

For work outside `erp-v2/`, inspect the legacy application independently. Do not
apply tenant-specific legacy behavior as a universal OVERVA rule, and do not
modify or retire the live legacy system merely because a similar capability
exists in OVERVA.
